# theMemeinator

This is my week 3 project. 
This week I designed something kinda like week 1; it's a speaker thingy that reads recording files and plays them.

# Components I used:

4xAA battery holder

USB_C PORT

Potentiometer (for volume)

five push switches (1 for reseting, 1 for ____, 3 for cataloging and choosing )

1 slide switch for power

ESP32 S3 Wroom-1

DFPlayer mini

MCP1825s

# Passive components:

Resistors

capacitors 

Schotty diode

two 2 pin JST PH connector
